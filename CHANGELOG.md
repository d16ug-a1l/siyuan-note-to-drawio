# Changelog

## 0.1.0

- One-click conversion of the current note into a draw.io flowchart generated by a cloud LLM (OpenAI-compatible chat completions API)
- Editor breadcrumb button and command entry ("AI 生成流程图" / "AI Flowchart")
- Settings panel for `baseURL`, `apiKey`, `model` and `temperature`
- Generated diagram is saved to `assets/drawio/*.drawio` via kernel HTTP API and embedded through the siyuan-drawio-plugin iframe block
- Chinese and English i18n
