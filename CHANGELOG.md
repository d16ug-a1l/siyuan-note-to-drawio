# Changelog

## 0.2.0

- New: generate **Mermaid diagrams** from the current note via the same LLM — the breadcrumb button now opens a menu with "生成 drawio 流程图" / "生成 Mermaid 图"
- Mermaid diagrams are inserted as fenced ```mermaid code blocks (rendered natively by SiYuan) via `/api/block/insertBlock`, anchored after the cursor block or appended at the document end
- New `aiMermaid` command (no default hotkey); the existing drawio command is unchanged
- New Chinese Mermaid system prompt with automatic diagram-type selection (flowchart / sequenceDiagram / classDiagram / stateDiagram-v2 / erDiagram / gantt / mindmap)

## 0.1.0

- One-click conversion of the current note into a draw.io flowchart generated by a cloud LLM (OpenAI-compatible chat completions API)
- Editor breadcrumb button and command entry ("AI 生成流程图" / "AI Flowchart")
- Settings panel for `baseURL`, `apiKey`, `model` and `temperature`
- Generated diagram is saved to `assets/drawio/*.drawio` via kernel HTTP API and embedded through the siyuan-drawio-plugin iframe block
- Chinese and English i18n
