# siyuan-note-to-drawio

[中文文档](README.zh-CN.md)

![version](https://img.shields.io/badge/version-0.4.0-blue)
![license](https://img.shields.io/badge/license-MIT-green)

A [SiYuan Note](https://b3log.org/siyuan) plugin that converts the current note into a diagram in one click. Diagrams are generated by a cloud LLM through any OpenAI-compatible chat completions API. Two output formats are supported:

- **draw.io flowchart** — saved as a `.drawio` file under `assets/drawio/` and embedded in the note in a format fully compatible with the [siyuan-drawio-plugin](https://github.com/zt8989/siyuan-drawio-plugin)
- **Mermaid diagram** — inserted as a fenced ` ```mermaid ` code block and rendered natively by SiYuan (flowchart / sequence / class / state / ER / gantt / mindmap, picked automatically by the LLM)

## Features

- Preview-first generation dialog: pick the diagram type (drawio / Mermaid), Mermaid subtype (or let the LLM decide), insert position (at cursor / end of document), and add extra instructions before generating
- Content scope selection: generate from the whole document or from a hand-picked set of blocks via a hierarchical checkbox tree of the current document
- Preview the generated source before inserting — editable for Mermaid, read-only for drawio XML
- One-click "AI Flowchart" button in the editor breadcrumb opens the dialog (two commands also open it with the type preselected, hotkeys configurable)
- Calls any OpenAI-compatible endpoint (DeepSeek, OpenAI, Moonshot, etc.) through the SiYuan kernel forward proxy — no CORS issues
- Saves the generated diagram as `<title>-<timestamp>-<random>.drawio` in `assets/drawio/`
- Inserts a drawio-plugin-compatible iframe block at the cursor position — double-click to edit the diagram in draw.io
- Configurable `baseURL` / `apiKey` / `model` / `temperature` / default type & insert position in the plugin settings
- Chinese and English UI

## Install

1. (Optional, only needed for drawio flowcharts) Install and enable the **drawio plugin** (`siyuan-drawio-plugin`) from the SiYuan bazaar — Mermaid diagrams are rendered natively by SiYuan and need no other plugin.
2. Install this plugin from the bazaar, or build it manually (see Development below) and copy it to `data/plugins/siyuan-note-to-drawio/`.

## Usage

1. Open the plugin settings and configure:
   - **API Base URL** — e.g. `https://api.deepseek.com/v1`
   - **API Key** — your key for the endpoint
   - **Model** — e.g. `deepseek-chat`
   - **Temperature** — default `0.2`
2. Open a note that describes a process or workflow.
3. Click the ✨ button in the editor breadcrumb to open the generation dialog (or run the "AI Flowchart" / "Generate Mermaid diagram" command to open it with the type preselected).
4. In the dialog: choose the diagram type, Mermaid subtype (default auto) and insert position, optionally add extra instructions; expand **Content scope** to generate from selected blocks instead of the whole document, then click **Generate**.
5. Review the preview (Mermaid source is editable), then click **Insert into note**:
   - drawio flowcharts are saved as `.drawio` files and inserted (double-click to edit in draw.io)
   - Mermaid diagrams are inserted as ` ```mermaid ` code blocks (rendered natively by SiYuan)

## Privacy & Security

- Your API key is stored only in the plugin's private storage inside the local workspace (`data/storage/petal/`) and syncs with the workspace
- LLM requests are sent through the SiYuan kernel forward proxy; the plugin connects to no other server
- Generated `.drawio` files live in `assets/drawio/` like ordinary asset files

## Development

Requires Node.js >= 24 and npm.

```bash
npm install
npm run dev      # development build (watch mode)
npm run deploy   # copy the dev build into your SiYuan workspace
```

`npm run deploy` copies `index.js`, `index.css`, `plugin.json`, `i18n/` and `README*.md` into `<workspace>/data/plugins/siyuan-note-to-drawio/`. The workspace path must be provided via the `SIYUAN_WORKSPACE` environment variable:

```bash
SIYUAN_WORKSPACE=/path/to/workspace npm run deploy
```

Then in SiYuan: **Settings → Bazaar → Downloaded → Plugins**, enable `siyuan-note-to-drawio` (reload SiYuan if it does not appear).

Production build (produces `dist/` and `package.zip`):

```bash
npm run build
```
