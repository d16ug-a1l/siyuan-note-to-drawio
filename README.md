# siyuan-note-to-drawio

[中文文档](README.zh-CN.md)

A [SiYuan Note](https://b3log.org/siyuan) plugin that converts the current note into a **draw.io flowchart** in one click. The flowchart is generated by a cloud LLM through any OpenAI-compatible chat completions API, saved as a `.drawio` file under `assets/drawio/`, and embedded in the note in a format fully compatible with the [siyuan-drawio-plugin](https://github.com/zt8989/siyuan-drawio-plugin).

## Features

- One-click "AI Flowchart" button in the editor breadcrumb (also available as a command with configurable hotkey)
- Calls any OpenAI-compatible endpoint (DeepSeek, OpenAI, Moonshot, etc.) through the SiYuan kernel forward proxy — no CORS issues
- Saves the generated diagram as `<title>-<timestamp>-<random>.drawio` in `assets/drawio/`
- Inserts a drawio-plugin-compatible iframe block at the cursor position — double-click to edit the diagram in draw.io
- Configurable `baseURL` / `apiKey` / `model` / `temperature` in the plugin settings
- Chinese and English UI

## Install

1. Install and enable the **drawio plugin** (`siyuan-drawio-plugin`) from the SiYuan bazaar — this plugin depends on it to render and edit diagrams.
2. Install this plugin from the bazaar, or build it manually (see Development below) and copy it to `data/plugins/siyuan-note-to-drawio/`.

## Usage

1. Open the plugin settings and configure:
   - **API Base URL** — e.g. `https://api.deepseek.com/v1`
   - **API Key** — your key for the endpoint
   - **Model** — e.g. `deepseek-chat`
   - **Temperature** — default `0.2`
2. Open a note that describes a process or workflow.
3. Click the ✨ button in the editor breadcrumb (or run the "AI Flowchart" command).
4. Wait a few seconds — the flowchart is generated, saved as a `.drawio` file, and inserted at the cursor position.

## Development

Requires Node.js >= 24 and npm.

```bash
npm install
npm run dev      # development build (watch mode)
npm run deploy   # copy the dev build into your SiYuan workspace
```

`npm run deploy` copies `index.js`, `index.css`, `plugin.json`, `i18n/` and `README*.md` into `/path/to/workspace\data\plugins\siyuan-note-to-drawio\` by default. Override the workspace path via the `SIYUAN_WORKSPACE` environment variable:

```bash
SIYUAN_WORKSPACE=/path/to/workspace npm run deploy
```

Then in SiYuan: **Settings → Bazaar → Downloaded → Plugins**, enable `siyuan-note-to-drawio` (reload SiYuan if it does not appear).

Production build (produces `dist/` and `package.zip`):

```bash
npm run build
```
